核心能力

6 大能力域，覆盖 LLM 出口安全全链路

透明出口引流

Cilium eBPF 或 iptables TPROXY 透明拦截所有 LLM 出站流量，业务 Pod 零改造、零 sidecar、不改 SDK。

Cilium eBPF iptables TPROXY 零侵入

多检测器流水线

rules -> heuristic -> encoding -> semantic 四段流水线，返回 [0,1] 归一化 risk_score。

正则 熵检测 Base64 还原 语义预留

风险打分 + 策略引擎

按 ArgusSecurityPolicy 阈值选 allow / block / degraded，支持 monitor / enforce 双模式。

monitor enforce fail-open fail-closed

事件审计归档

AIEvent 流式上报 controller，按 cluster_id/date/event_id 落盘 JSONL，at-least-once 语义。

gRPC stream JSONL 幂等 at-least-once

Pod 身份溯源

gateway 零 RBAC，身份全靠 controller PodIdentityService.Lookup 查 informer cache。

零 RBAC informer cache 24h ring buffer

TLS 解密 + CA 管理

被动观测 / TLS 解密双模式，MutatingWebhook 自动注入 CA 根证书到业务 Pod。

B 模式解密 A 模式直通 Webhook 注入

快速上手

点击命令卡片可复制到剪贴板

一键开发环境

启动 Minikube + 构建镜像 + 部署 K8s + 端口转发，一条命令拉起完整开发环境。

$ make run
自动检测 Docker 资源 make kill 停止保留数据 make dev-logs 查看日志

编译二进制

编译 gateway 和 controller 两个二进制到 bin/ 目录，多阶段 Docker 构建产出 distroless 镜像。

$ make build
make fmt 格式化 make lint 静态检查 make test 单元测试

生成 Proto 桩

基于 buf 生成 gRPC 桩代码，5 份 proto 契约 -> pkg/pb/argus/*/v1alpha1/。

$ make proto
make crd 生成 CRD make tidy 整理依赖 make all 全量检查
